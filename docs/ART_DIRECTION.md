# CozyTown 纯像素美术方向

## 1. 当前阶段

CozyTown 采用纯像素 2D 美术。本文件规定 A0 风格锚点和 A1 可玩资源的共同语言；A0 只用于确认画面比例、色板、轮廓和材质，不作为可直接切片的生产 Sprite。A1 已完成首批全量 Production 资源及 Scene-01a 至 Scene-01i 自动接线；最终人工画面验收待执行。

当前玩法范围保持不变：一张小镇地图、七种交互语义、10 个物理交互实体，3 种作物、3 种鱼、1 只鸡、5 个料理、18 个物品和 4 名 NPC。10 个实体包含 Mina、Eli、Ren 和 Sora 的四个独立世界入口；美术资源不得新增野外、室内地图、季节、天气、战斗、NPC 日程或新的交互语义。

上述范围记录 A1 基线。2026-09-05 新增 [T1 扩镇与居民日常规划](TOWN_LIFE_PLAN.md)：允许在独立玩法阶段制作四户 NPC 住宅、对应屋顶前景及四人行走帧。T1-1 已扩展灰盒场景并复用现有住宅及屋顶，Production 源图片未改变；正式四户差异化外观与行走帧留在 T1-4。T1 延续本文件的像素规格和色板，不把日程作为 A1 美术附带功能。

## 2. 像素规格

| 项目 | 规格 |
| --- | --- |
| 原生逻辑画面 | `320×180 px`，只允许整数倍显示 |
| 基础 Tile | `16×16 px` |
| Unity Pixels Per Unit | `16` |
| 玩家与 NPC 单帧 | `24×32 px` |
| 小物件与物品图标 | `16×16 px` |
| 视角 | 3/4 俯视；不使用等距投影 |
| 光源方向 | 左上方 |
| 主色板 | 固定 32 色暖色田园色板 |
| 透明边缘 | 硬透明；不使用半透明抗锯齿 |

所有生产资源使用统一像素密度。人物、建筑、地面和 UI 不得分别模拟不同大小的像素块。阴影使用实色像素块或受控抖动，不使用模糊投影、景深、体积光和 HD-2D 后期效果。

主角每个移动帧使用独立的 `24×32` 精确像素源。可见包络从脚底 `y=0` 延伸至 `y=29` 或 `y=30`，水平边界保持在 `x=2..21` 内，中心保持在 `x=11..12`；脚底至少有 2 个不透明像素，所有不透明像素必须通过四邻域连接到脚底，全部 12 帧的可见高度差不得超过 1 像素。左右对应帧的整体镜像轮廓交并比不得低于 `0.9`，底部 8 行不得低于 `0.85`。

A1 固定色板如下；透明色不计入 32 色：

```text
#1F1B24 #3B1F1B #FFF4D6 #E6D5B8 #B49A7A #6F5A4A #214E24 #3E7B32
#76B947 #B7D65C #5B2E1A #8A3B12 #A95A2A #D28A48 #D75B18 #F68B2B
#FFC05A #F2D35A #8F2D2D #D9483B #F36B4F #1F4E66 #2F7891 #58A6B8
#8ED0CE #6A4C93 #9B6BCB #8C4F32 #C98256 #F0B47A #FFD3A1 #D7DEE8
```

## 3. 视觉语言

- 场景使用暖草绿、泥土棕、池水蓝、蜂蜜木色和陶瓦红，交互目标与背景保持明度或色相差。
- 人物使用紧凑的 2 至 2.5 头身比例；脚底中心作为世界定位基准。
- 建筑正面入口保持可辨认，屋顶、墙面和门窗遵循同一左上光向。
- 作物、鱼、鸡蛋和料理在 `16×16 px` 下依靠轮廓和主色区分，不依赖文字。
- UI 图像只提供边框、按钮状态和图标；最终文字由 Unity 字体渲染。
- 现有游戏只作为媒介与可读性参考，不复制其角色、地图、建筑、图标或调色板。

## 4. 资产分层

```text
ArtSource/
├─ Generated/A0/    A0 生成式源图；不由 Unity 导入
├─ Generated/A1/    A1 生成式源图；不由 Unity 导入
├─ Authored/A1/     A1 原生尺寸确定性像素源；不由 Unity 导入
├─ Previews/A0/     A0 确定性整数倍预览
└─ Previews/A1/     A1 确定性 4× 最近邻预览

Assets/CozyTown/Art/
├─ References/A0/    风格锚点；不被运行时代码或正式场景引用
├─ Production/       通过技术与视觉验收后才能进入的可切片资源
└─ Scene/Tiles/      从 Production Sprite 派生的场景 Tile 适配资产
```

`References/A0` 与 `Production` 必须分离。A1 生成式源图只作为草稿或编译输入；`Authored/A1` 保存已在原生画布内完成的精确像素源。确定性工具完成源尺寸与色板校验、必要的生成式源图裁切、二值 Alpha、重排、切片和 4× 预览后，输出才可进入 Production。

| 文件 | 内容 | 验证问题 |

## 6. A1 最小生产范围

A1 只替换当前 MVP 可以消费的画面：小镇地面与边界装饰、4 个功能建筑、池塘、6 块农田、玩家四方向移动、4 个静态世界 NPC、4 个 NPC 头像、3 种作物成长状态、母鸡状态、18 个物品图标、UI 皮肤和交互提示。四名 NPC 各有一个独立对话入口，但不增加行走、日程、任务或关系系统。

以下内容不进入 A1：室内地图、野外、季节、天气、昼夜光照、工具动作全集、NPC 行走日程、更多作物/动物/料理、建筑升级、标题画面和宣传插画。

## 7. 工具边界

内置图像生成用于 A0 风格锚点和 Production 草稿。确定性 Unity Editor 工具负责尺寸收敛、锁色板、二值 Alpha、整数倍预览和导入验收；人工复核负责语义可读性、光向和原创性。Pixelorama 1.2.1 已作为人工修像素的本地后备工具安装，自动化管线不依赖它。Tile 接缝、透明 Sprite Sheet 和逐帧动画仍需逐像素复核，不能只凭自动检查准入。
