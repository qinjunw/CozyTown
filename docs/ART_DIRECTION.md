# CozyTown 纯像素美术方向

## 1. 当前阶段

CozyTown 采用纯像素 2D 美术。本文件规定 A0 风格锚点和后续 A1 可玩资源的共同语言；A0 只用于确认画面比例、色板、轮廓和材质，不作为可直接切片的生产 Sprite。

当前玩法范围保持不变：一张小镇地图、商店、NPC、床、农田、鸡舍、池塘和厨房 7 个既有交互点，3 种作物、3 种鱼、1 只鸡、5 个料理、18 个物品和 4 名 NPC。美术资源不得新增野外、室内地图、季节、天气、战斗、NPC 日程或新的可交互对象。

## 2. 像素规格

| 项目 | 规格 |
| --- | --- |
| 原生逻辑画面 | `320×180 px`，只允许整数倍显示 |
| 基础 Tile | `16×16 px` |
| Unity Pixels Per Unit | `16` |
| 玩家与 NPC 单帧 | `16×24 px` |
| 小物件与物品图标 | `16×16 px` |
| 视角 | 3/4 俯视；不使用等距投影 |
| 光源方向 | 左上方 |
| 主色板 | 24–32 色；A1 前锁定具体色值 |
| 透明边缘 | 硬透明；不使用半透明抗锯齿 |

所有生产资源使用统一像素密度。人物、建筑、地面和 UI 不得分别模拟不同大小的像素块。阴影使用实色像素块或受控抖动，不使用模糊投影、景深、体积光和 HD-2D 后期效果。

## 3. 视觉语言

- 场景使用暖草绿、泥土棕、池水蓝、蜂蜜木色和陶瓦红，交互目标与背景保持明度或色相差。
- 人物使用紧凑的 2 至 2.5 头身比例；脚底中心作为世界定位基准。
- 建筑正面入口保持可辨认，屋顶、墙面和门窗遵循同一左上光向。
- 作物、鱼、鸡蛋和料理在 `16×16 px` 下依靠轮廓和主色区分，不依赖文字。
- UI 图像只提供边框、按钮状态和图标；最终文字由 Unity 字体渲染。
- 现有游戏只作为媒介与可读性参考，不复制其角色、地图、建筑、图标或调色板。

## 4. 资产分层

```text
Assets/CozyTown/Art/
├─ References/A0/    风格锚点；不被运行时代码或正式场景引用
└─ Production/       通过技术与视觉验收后才能进入的可切片资源
```

`References/A0` 与 `Production` 必须分离。生成式图片进入 A0 后，需要经过网格校正、锁色板、透明边缘清理、切片和逐帧一致性检查，才能复制或重制为 Production 资源。

## 5. A0 风格锚点包

| 文件 | 内容 | 验证问题 |
| --- | --- | --- |
| `a0_style_town.png` | 小镇同屏构图，展示 7 个既有功能地标、玩家与一个 NPC 世界交互点 | 地图比例、地标可读性、整体像素密度 |
| `a0_palette_board.png` | 草地、泥土、水、木材、屋顶、肤色和 UI 的候选色板 | 色相关系与明度层级；不是最终调色板文件 |
| `a0_characters.png` | 玩家、Mina、Eli、Ren、Sora 的正面静态造型 | 五名角色的轮廓和配色区分 |
| `a0_environment.png` | 草地、道路、耕地、水、围栏、商店、住宅/床、厨房和鸡舍样张 | 材质、光向和 16px 网格语言 |
| `a0_ui_items.png` | HUD、对话框、按钮和 18 个物品图标样张 | 小尺寸图标与 UI 层级 |

A0 图片是项目内的设计输入，不声明为无缝 Tile、动画帧或最终 UI。A0 全部通过人工验收后，才开始 A1 的逐像素生产。

## 6. A1 最小生产范围

A1 只替换当前 MVP 可以消费的画面：小镇地面与边界装饰、4 个功能建筑、池塘、6 块农田、玩家四方向移动、一个世界 NPC 表现、4 个 NPC 头像、3 种作物成长状态、母鸡状态、18 个物品图标、UI 皮肤和交互提示。NPC 仍共用一个世界交互点，不增加 4 个 NPC 日程或独立交互对象。

以下内容不进入 A1：室内地图、野外、季节、天气、昼夜光照、工具动作全集、NPC 行走日程、更多作物/动物/料理、建筑升级、标题画面和宣传插画。

## 7. 工具边界

内置图像生成用于 A0 风格锚点和 Production 草稿。可切片的 Tile、透明 Sprite Sheet 和逐帧动画需要像素编辑器完成网格对齐、锁色板、清边和修帧。项目已安装 Unity Aseprite Importer，但当前开发环境未发现 Aseprite 桌面程序；进入 A1 前需要安装 Aseprite、LibreSprite 或 Pixelorama 之一。
