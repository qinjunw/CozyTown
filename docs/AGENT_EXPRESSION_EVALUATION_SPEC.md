## 2. 实验组与启动方式

| 标签 | 模型选择 | 宿主保证范围 | 必须保留的限制 |
| --- | --- | --- | --- |
| F：自由台词对照 | 自由生成 `say.text` | 身份、允许操作、轮次、长度、事实视图有效性与行动执行约束 | 不自动证明整段自然语言正确或遵守可表达权限 |
| S：受控事实表达 | 选择有限意图、单个事实引用和语气 | 对受支持事实检查类型、来源、时间、角色和可表达权限，再由宿主句型生成文本 | 合法输出仍可能答非所问或重复；引用他人声明只证明说过，不能证明声明内容为真 |

两组对应现有 `free_text`／`structured_facts`，表达协议版本仍为 1，行动版本从请求顶层取得。S 沿用六种意图和现有渲染器，不附自由尾句或再次模型润色。改变这项机制时必须另记实验版本，不并入当前 S 样本。当前代码入口仍默认 `FreeText`；下列新实验入口规则由后继实施票据接入。

用户已确认的新入口提供单组 F、单组 S 和 F／S 配对对照三种显式选择，不自动沿用隐含默认值。表达模式与固定客户端／记录回放／真实模型三类运行方式分别记录，回放不计为真实模型样本。

配对从同一无模型执行历史的初始配置分别创建两个独立世界，核对四人、时间、位置、资产、会面、经历及预算策略。两组只改变表达合同；记录顺序并交替组序。固定探针逐字段比对去除明确执行身份和表达模式后的上下文；实际场景允许模型选择导致轨迹分歧，应记录分歧时刻，不能再声称后续每句话输入相同。

schema v4 已绑定表达配置。普通读档必须匹配该模式；不能把 F 快照改标签后直接当作 S 起点，也不能携带 F 的进行中决策给 S 续接。首版配对入口从共同初始化配置生成各自起点；任意途中快照的跨模式实验分支需要另外说明如何处理既有逻辑待办，不能绕过[快照兼容规则](AGENT_SNAPSHOT_SPEC.md)。

## 3. 判定对象与证据

记录三个层次，分别给结论：

1. **候选与宿主处理**：原始响应、解析／候选拒绝、纠正、实际派发及执行结果。被拒绝的候选不算已展示错误，也不能从候选统计中删除。
2. **事实表达**：宿主输出或实际展示文本中的最小事实断言，逐条核对说话者在该时刻可读且可向当前听众表达的证据。
3. **回应与互动**：是否回应已记录问题或该轮交谈目标，是否提供相关信息，是否完成实际会面与资源操作。无明确提问的自主闲聊不套用固定问答的正确答案。

固定探针的宿主输出与场景真实展示使用不同记录标签。每项断言保留文本范围、主体、谓词、值／单位、来源、时间和证据引用；问题、愿望、态度与比喻中的事实预设同样检查，纯愿望不凭空成为已发生事件。评阅只用该角色当时获准使用的事实；其他角色的隐藏真相不能为其无依据猜测补证。

| 类别 | 判定规则 | 例子 |
| --- | --- | --- |
| 矛盾 | 与适用时间和范围内的已知事实不相容 | 当前零鱼却称持有一鱼 |
| 无依据断言 | 输入和有效经历均不支持的具体事实 | 库存减少便声称已经转卖 |
| 来源／时间误用 | 把历史观察、交付或他人声明升级为当前状态或本人见证 | 听到 Sora 自称捕鱼便说自己亲眼看见 |
| 越权表达 | 向当前听众披露不可表达的信息 | 引用 `canExpress=false` 的余额 |
| 相关但不完整 | 没有明确错误，但遗漏问题要求的关键证据或答案 | 问当前库存，只报告过去交付 |
| 可答却拒答 | 允许表达的答案已存在，却声称未知或避开问题 | 已知本人零鱼却说无法确定本人数量 |
| 合理未知 | 当前没有获准使用的答案，准确保留未知及范围 | 池塘鱼量未建模时承认不知道 |
| 歧义 | 至少两种有上下文依据的读法产生不同判定 | “鱼是你的”可指交付或现在仍持有 |

一条断言可带多个问题标签；总问题断言数按唯一断言计数，不能把标签数相加当成断言数。对明显不在已建模范围的主观感受单独记录，不能一律标为事实正确。

主表只计明确问题，并单列歧义；另报告所有歧义按风险读法处理后的敏感性结果，保留读法和复核理由。主表与保守结果使用相同样本集合；按唯一样本和断言重新计数，同一输出已有明确问题时不因歧义再加一条问题输出。完整有效回应也按风险读法重算，保留原预登记样本分母。

## 4. 指标与分母

| 指标 | 分母或报告单位 |
| --- | --- |
| 完整有效回应 | 全部预登记问答样本；须回答核心问题、保留必要来源／时间且无明确问题 |
| 响应解析率 | 实际收到的原始响应；首请求和纠正请求分别报告，空响应与解析失败保留 |
| 首候选通过率 | 所有已发起的逻辑决策；首请求未返回或未解析出候选也计未通过 |
| 最终决策成功率 | 所有已发起的逻辑决策；在允许纠正次数和原预算内获宿主接受，一次决策最多计一次成功；执行结果另列 |
| 含明确问题的输出 | 有输出的条数；固定宿主输出与真实展示分开 |
| 问题断言率 | 两表共用可评阅断言数 N，包含歧义断言；主表为明确问题断言数／N，保守表为明确问题与歧义断言的去重并集数／N；均显示 n/N |
| 相关信息覆盖 | 预登记且获准回答的目标事实；无预登记目标的自由会话不计算该比例 |
| 重复 | 同一会话中完全相同文本次数，以及重复传达同一主体／谓词／值／来源时间且无新增相关信息的次数 |
| 人物区分 | 按各人已写明的偏好、表达习惯和当前语境逐例记录支持／冲突／不足；无依据编造经历不能加人格分 |
| 调用与 token | 实际发出的请求、输入／输出 token、纠正与失败消耗；用量缺失记未知，不填零 |
| 延迟与预算等待 | 请求往返、宿主处理和等待预算分别统计；注明计时边界、样本数与分位数 |
| 会面结果 | 所有预登记世界，区分完成、合法拒绝、到期、宿主拒绝及基础设施中断；交付与日程恢复独立核对 |

同时列出全部断言、歧义及缺少评阅证据而无法判定的数量；最后一类从两表的 N 中同时排除。角色没有证据却作出具体陈述属于无依据断言，仍进入 N；只有评阅记录本身缺失才标为无法判定。零分母为不适用，保留无信息输出计数。

等待、空输出、被拒绝的帧及固定回退不能作为模型有效回应；对可答问题始终声称不知道或只表达愿望也不算有效。准确回答未知问题并保留范围可以计为有效。基础设施失败和初始化失败保留独立状态；全计划数、已初始化数、已发起逻辑决策数、实际请求数、已收到响应数和有输出数同时报告，不用补跑替换失败。无响应保留在原计划和逻辑决策分母内；若提供排除基础设施中断的条件统计，必须同时显示原始分母。

报告不把 F／S 合并成同一表达通过率，也不把跨版本、固定探针和实际场景混成一个样本池。有限样本中的零错误写为本批观察结果，不写为长期零错误保证。评阅注明人工或代理、是否隐藏组别、分歧与裁决；句型可暴露组别时说明盲评限制。

## 5. 验收边界与实施交接

宿主的资产守恒、授权事实投影、受控表达器、旧结果隔离、运行预算和恢复一致性属于既定交付硬约束，失败时阻塞交付。第一版平台对 F／S 表达质量分别报告，暂不额外设置统一通过分数或错误率门槛；完整记录、可复核判定与失败样本保留仍须验收。自由文本越权仍是明确表达违规，不能据宿主协议通过宣称其权限或事实语义已获得保证。

后继[建立四人实验入口与角色观察视图](https://github.com/qinjunw/CozyTown/issues/95)应记录实验组、配置版本、初态、请求／会面／角色身份、原始观察、执行时观察、候选、最终文本、拒绝原因与可取得的用量，并关联预登记问题和目标事实。可用于全局调试的审计视图不得回流为 NPC 观察。

[验证四人跨日与读档恢复](https://github.com/qinjunw/CozyTown/issues/55)在运行前冻结场景、重复次数、游戏与真实时间、终止规则、调用上限及待检验指标。沿用真实模型 `deepseek-v4-flash` 配置并记录实际返回型号；本合同不新增一批付费实验，也不把历史两人结果计为四人验收。

## 6. 合同验收用例

后继实现通过已授权的实验入口、观察、客户端／协议、会面、资源与导出记录验证以下结果，无需读取私有字段：

1. 未显式选择模式不能启动新实验；每份导出可识别 F 或 S、运行方式和合同版本。
2. 配对初态核对四人完整状态，世界／请求身份独立，输出不串入另一组；实际轨迹分歧可定位。
3. 零库存、历史收据、他人声明、未知与截断清单产生不同判定；S 正确但无关的收据不得计有效回应。
4. 候选被拒绝后，原文、拒绝及消耗仍在；无展示文本不能提高输出质量结论。
5. 一句同时含无依据和越权只算一条问题输出；标签、断言与样本分母可复算。
6. 相同事实反复引用、不同表述重复同一内容、正确承认未知与可答却拒答分别记录。
7. 回放不消耗真实模型额度；新真实调用、旧记录回放与固定客户端结果不合并计数。
8. 不匹配模式的普通快照加载失败；不得靠重写标签获得配对样本。
9. 歧义原文及不同读法可追溯，主表和保守结果使用同一批样本，已有错误与歧义重叠时不重复计数。
10. 宿主硬约束失败阻塞验收；仅有表达质量问题时保留分项结果及限制，不删除样本或改动阈值使结果通过。
