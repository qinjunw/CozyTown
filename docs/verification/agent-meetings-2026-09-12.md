## 真实场景结果

用户选择请求型号 `deepseek-v4-flash`，6 次场景调用均返回型号 `deepseek-flash`。请求采用非流式 JSON 输出、关闭思考、每次最多 512 输出 Token。首次连通检查和场景调用合计限制为 12 次，实际用了 7 次；测试完成后代理停止，剩余 5 次未使用。

| 指标 | 本次观测 |
| --- | --- |
| 场景提供方调用 | 6 次：邀请、接受、4 轮发言 |
| 场景 Token | 输入 5,024，输出 299，总计 5,323 |
| 包含首次连通检查 | 7 次调用，5,689 Token |
| 6 次提供方耗时 | 935–1,212 ms，算术平均 1,037 ms |
| 从首次机会到交谈完成 | 约 29.88 现实秒，包含等待约定时间与实际行走 |

场景在第 1 天 12:15 开始，不输入玩家邀请或对话指令。约 2.02 秒后形成承诺，Sora 仍在厨房工作；13:00 开始赴约，约 13:06 双方分别到达 `(-3, -1.4)` 和 `(-3, 0.4)`，此后才发生模型发言。13:14 左右完成 4 轮交谈，双方活动释放，目标立即回到各自当时的休息日程。随后测试显式推进到 14:40，确认两人均已到达各自工作地点。

真实场景使用两位居民的决策配置。默认游戏启用代理时配置四位居民；四人共同负载和多日成功率仍属于后续验证范围。

本地证据为 `Logs/agent-meetings-live-scene.json`、`Logs/agent-meetings-live-proxy.jsonl` 和 `Logs/agent-meetings-live-conversation.png`。JSON 报告保留脱敏调用及场景记录。截图包含共享工作区另行修改的美术，不作为发布分支的美术基准；隔离图形测试使用发布提交自己的场景和素材。批量截图将已有对话 Canvas 临时交给场景相机渲染，并关闭像素相机缩放以导出可读文字，完成后恢复设置。

## 模型表现与边界

执行链通过不等于台词事实一致性通过。本次约 13:08–13:10 的前两句使用了 “Evening”；后续提到鲈鱼、鲤鱼及配料，但宿主没有确认相应鱼获或库存。模型说出的这些内容只作为发言记录，没有生成物品、食材交付或生产完成事件。

因此，本次证据支持“模型候选可以完成受检查的两人会面”，不支持长期成功率、稳定人设或可靠世界事实理解的结论。显式时段、已确认资源事实披露和重复场景的语义评测，已作为后续模型验证的输入。

会面与经历目前只保存在内存，读档或换世界会清空。资源协作、持久化和长期关系变化尚未实现。架构决策见 [ADR-0017](../adr/0017-resident-meeting-commitments.md)，调用契约见[代理协议](../NPC_AGENT_PROTOCOL.md)。

## 复现与密钥

固定测试无需密钥。代理运行和真实测试开关见 [本地代理说明](../../Tools/agent_proxy/README.md)。密钥由代理从仓库外的 CozyTown 配置读取，不进入 Unity 请求、场景或仓库。发布前按实际密钥检查待提交内容，未发现密钥；代理日志仅记录候选、结果码、型号、Token 和耗时。

真实模型的接口约定依据 [DeepSeek 官方文档](https://api-docs.deepseek.com/zh-cn/)、[思考模式控制](https://api-docs.deepseek.com/zh-cn/guides/thinking_mode/) 和 [JSON Output](https://api-docs.deepseek.com/guides/json_mode/)。服务返回的型号按实际响应记录，不据请求别名推断固定权重。
