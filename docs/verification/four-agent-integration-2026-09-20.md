# 四人跨日、重复读档与表达对照：集成验证

本轮完成预登记的 16 世界评测：15 世界跨日并通过严格回放，1 世界因期限停止；244 次真实调用、72 条提交台词全部保留。固定宿主约束及源码绑定回归通过，交接候选版本验收。第二天的大量观察过期拒绝和自由表达无依据断言仍是已测限制。

本批按冻结的 `cross-day-v1` 输入运行四种资源场景，各做两次 F/S 配对，共 16 世界。每世界最多 32 次提供方尝试和 600 现实秒，全批最多 512 次；每个新世界先核验四人、资产、时间及零调用，再开放提供方请求。第一轮 F→S，第二轮 S→F。完成的实验包在独立新场景严格 Replay，回放不调用模型。

每世界从第 1 天 12:00 推进至 16:00，保存 `post_day1`，再推进一分钟并连续读取同档两次；随后睡眠到第 2 天 04:00、05:00，再正常推进到 16:00。901 次正常推进按至少 0.5 现实秒间隔执行。世界完成与会面成功分别统计；模型拒绝、超时、取消及观察过期保留为结果。

两名独立 Codex 代理只读取角色获准的盲包，逐条记录最小断言、原文范围、事实引用、来源时间和表达权限。评阅者的实际后端版本不可取得，记未知；组别标签被隐藏，但 S 句型可能透露组别，不声称完全盲评。主代理核对分歧并记录裁决，原始两份报告保留。

事实 N 包含有依据、明确问题和歧义。主表为明确问题/N，保守表为明确问题与歧义的唯一并集/N；两表分母相同。角色缺少证据却作具体断言属于无依据，仍在 N 中；只有评阅证据本身缺失才同时从两表排除。无依据不等于已经证明命题在全局世界中为假。

本批没有预登记固定问题，`question=null`、`targetFactIds=[]`；固定问答的有效回应率和目标事实覆盖率不适用。相关性、合理未知、重复、人物配置兼容性分别报告。简短礼貌语或平实措辞可以支持某个人设侧面，不能据此声称不同人物已能被可靠区分。

## 结论、适用限制与交接

本批未记录宿主资产、权限、预算或恢复硬约束违规；确定性与故障覆盖由 H01–H07 的固定测试承担。15 个完成包通过新场景严格 Replay，未完成包没有执行 Replay，归档的 `completeForPlannedStudy=false` 如实保留。当前证据足以进入候选交付验收，不证明所有预登记世界均成功，也不证明 NPC 在第二天持续做出有效自主选择。

后续行为实验应优先研究移动中的观察过期如何减少有效行动，以及在不引入未经授权事实的条件下提高 S 的信息增量。它们属于新的行为/表达研究范围；本轮没有为改善表面通过率放宽观察校验或追加真实调用。

第一版范围仍是四人 Agent 实验平台。已有动作由事件触发并受宿主校验，完整快照与记录回放服务于可复查实验；台词中的捕鱼、烹饪、草药、长期关系等内容不自动成为可执行玩法或资源事实。后继交付任务需从包含全部依赖的干净候选检出验证启动、观察、存读档和回放，并核对文档及 PR 状态。
