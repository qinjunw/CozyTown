## 验证的行为

- 默认休息窗口由世界事件触发，不需要玩家自然语言输入；普通帧不重复请求，其他居民保持自身状态。
- 滚动调用预算、实际在途并发、居民冷却、工具往返上限及排队有效期生效。失败与续调计入预算。
- 地点信息先披露本人已知地点 ID，查询后在同一决策中增加该地点可达性。原请求不变，其他居民的人设和已知地点没有进入请求。
- 世界重建、修订变化、游戏机会过期和现实时间超时会结束旧决策。客户端忽略取消时仍占用并发槽，迟到候选不能改变世界。
- Unity 帧更新能自动消费候选，并通过现有身体沿路线移动。读档和换世界保持调用预算、拒绝旧响应；重复绑定不重启决策会话，销毁控制器取消请求。
- JSON 版本和操作检查、UTF-8 请求上限、已知及未知 Content-Length 的响应上限、HTTP 失败和取消在内存传输边界通过验证。批量启动器不因环境变量启用后台代理。
- 最近一次诊断保留本人上下文、最终候选和调用次数；格式错误与客户端故障可区分，下一次机会只收到同一世界内本人的结果码。

触发、预算、披露、读档、超时、上下文失效、释放、Unity 移动、编解码、传输、启动器和诊断均保留 RED → GREEN 运行结果。原始报告路径、SHA-256、通过数量、实现源文件 Git blob 记录在[验证数据](agent-decisions-2026-09-12.json)。最后一组诊断的 GREEN 由完整 EditMode 回归提供。

## 结论与后续边界

本阶段完成自动触发、有限上下文、受检查候选和实际人物执行的固定客户端闭环。规则、调用默认值与启用方式见 [ADR-0016](../adr/0016-bounded-autonomous-decisions.md) 和[代理协议 v1](../NPC_AGENT_PROTOCOL.md)。测试完成后仅补充 PRD 与本验证文档，运行代码和用例保持与受测提交一致。

真实模型调用次数为 0。仓库没有本协议的代理服务端，尚未测量真实模型质量、延迟、Token 或费用；调用预算按客户端调用计数，不代表供应商账单。Ren 与 Sora 的邀约、赴约、交谈和恢复日程由后继[自主会面任务](https://github.com/qinjunw/CozyTown/issues/53)实现，角色资源与跨日持久化也未在本轮交付。
