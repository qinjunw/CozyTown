## 行为规则

当前资源会面是固定价交易，没有赊账、筹资或未来生产承诺。缺料仍产生一次有界决策机会；本人已知无法支付时保留等待，收到邀请但本人缺货时保留拒绝，到场后本人无法支付时保留取消。过滤只依据本人的当前数量或余额，不使用对方资产形成可行性信号。

本人条件及缺口随请求披露。它只表示本人可提供当前条款所需付款或物品，不保证对方资源、容量、到场或最终交易成功。已交付对话不再检查交付前条件。等待沿用每计划每日一次的机会机制，表示放弃本次机会；当日后来增加资产不自动重试。无视允许操作的坏候选结束本次决策，未接受的邀请仍由原有期限释放，不记为角色主动拒绝。

邀约与接受入口重新读取执行者资产。邀约不足时不建立会面；接受时发现本人库存不足则取消未接受的会面并返回失败。交付继续使用原有双方原子验证，不把预检查当作资源预留。数量/价格及承诺参与者仍由宿主绑定。

资源请求使用独立协议版本，旧版普通活动与社交兼容；本轮不加入候选自动纠错、局部环境感知或新经济能力。

## 测试与账目

沿用已授权的公开边界：会面入口、角色经济快照、调度器/模型客户端、JSON 编解码/代理 HTTP 入口、Unity 实际居民状态。逐条 RED → GREEN，验证余额 24/25/26、库存 0/1/2、自方与对方隔离、请求后资产变化、非法候选、交付后对话及旧协议兼容。运行目标测试后完成 EditMode、PlayMode 和 Python 回归；共享工作区的美术和农场改动不进入隔离检出。

回归通过后冻结运行实现，复用四种真实初始场景：资源充足、卖方缺鱼、买方缺钱、买方已有鱼，每种三轮，共 12 轮。每轮新建世界并恢复双方资产、承诺和记忆；两人均使用真实模型，普通活动调用也计入预算。每轮最多 12 次请求，单代理总上限 96 次，沿用 v4-flash、关闭思考、512 输出 token 上限、7 秒提供方超时与无自动重试。失败占用原轮次并保留，不补跑到成功。

真实记录使用新证据目录和报告，不覆盖前次矩阵。分别报告模型在已筛选选项中的选择、协议失败、宿主拦截、实际交付、资产守恒、日程恢复和用量；系统过滤不计为模型推理改善。完成后推送分支与 Draft PR，结果回填当前票据和地图，仅关闭本票据。
