# 四人实验入口验证

## 范围与版本

- 票据：[建立四人实验入口与角色观察视图](https://github.com/qinjunw/CozyTown/issues/95)。
- 实施分支：`codex/four-agent-experiment-platform`，起点 `60f6ac4fa97eaadfe49a4191e68fa1cc55b7c180`。
- 使用 Unity `6000.5.5f1`、Python `3.13`；测试结果和原始实验包保留在本地忽略目录 `Logs/agent-platform/`。
- 本票验证固定策略、记录回放、编辑器入口和测量接口。未读取真实凭据，也未调用模型；真实行为矩阵由后续集成验证承担。

## 实现与可观察结果

编辑器菜单 `CozyTown > Agent Experiment` 要求选择 Fixed、Live 或 Replay。新实验须显式选择 F、S 或 F/S 配对，分别从完整四人初态创建世界。四种资源场景覆盖可交易、卖方无鱼、买方缺钱和买方已有鱼；Mina/Eli 社交会面与 Sora/Ren 资源会面均经共享调度器执行。操作步骤见[实验指南](../AGENT_EXPERIMENT_GUIDE.md)。

导出明确记录表达合同 `1.0` 及预登记计划引用；计划记录问题、目标事实和分母。未预登记时显式记录 `none`，不得据自由会话补造固定问答分母。配对保留相同计划引用，回放继承来源引用；这些字段不进入角色观察。

实验持有时间推进和玩家输入。保存、读取、睡眠及完成操作进入输入记录；初态、检查点和终态使用 schema 4 完整逻辑快照。读档保留真实请求账本，改变世界代次，旧世界的审计记录与当前角色记忆分别呈现。固定场景中两组会面结束后恢复日程；买鱼成功后双方各有一条鱼和 25 金币。

回复先进入完成队列，在记录的 Tick 交付给宿主。回放核对配置、时间和规范化请求，再提供录制回复；检查点、结果和完整终态不一致时停止。规范化只映射声明的临时身份字段，台词中的 GUID 字符串保留原文。回放包同时保留来源请求/回复及本次身份桥接字段。

Live 测量通过本机代理只读 GET `/status` 和 `/measurements` 获取，按 `decisionId`、`step` 和人物关联。共享代理调用计数标记为 `proxy_shared`；未提供的 Token 保持 null。导出注释使用 Trace 副本，不能改变录制或回放的权威记录。失败测量保留此前报告，界面明确提示。

## 验证记录

完整回归使用上述工作树：EditMode 共 1065 项，1064 通过、1 项需显式启用的模型实验跳过；图形 PlayMode 共 291 项，286 通过、5 项需显式启用的模型实验跳过；Python 70 项通过。完整回归后补齐表达合同版本和预登记引用，定向复测 EditMode 70 项、图形 PlayMode 11 项全部通过。计数与原始 XML 校验值见[测试结果摘要](four-agent-entry-evidence/test-results.json)。

完整回归包含下列公开边界：

| 边界 | 证据与结果 |
| --- | --- |
| 四人初态与固定行为 | 四种资源初态与 F/S 组合、交付前失去资金的取消行为均通过定向测试 |
| 实验包 | 61 项通过：完整/未完成包、必填字段、类型、配置一致性、合同与计划引用、检查点标签及路径边界 |
| 记录与回放 | Trace 19 项通过，包含先 RED 后修复的零 Tick/零调用完成轨迹 |
| 代理测量 | 10 项通过：关联与字段过滤、重复/错配拒绝、URI、取消、16 KiB 候选及 8 MiB 响应边界 |
| 真实场景会话 | 两组固定互动、F 导出、S 保存/读取/回放、篡改检查点拒绝、跨日结算回放通过 |
| 初始化与拒绝输入 | 两项审查发现先复现再修复；初始化保存失败后禁止派发，无效时间推进不进入可回放输入 |
| 四人每分钟 8 次争用 | F/S 两项通过：实际滚动窗口不超过 8 次、物理请求最多 2 个，等待与会面到期后恢复日程，下一天可再次派发 |

| 表达合同元数据 | 16 个非法输入用例及 1 个会话导出用例先 RED；补齐后验证必填合同/计划引用、配对冻结值、导出与回放继承 |
| Python 代理 | `python -B -m unittest discover -s Tools/agent_proxy -p 'test_*.py' -q`：70 项通过 |

独立 Standards/Spec 审查发现并修复了四个边界：导出 DTO 可修改权威轨迹、初始化保存失败后仍可推进、被拒绝的时间输入污染轨迹，以及非 batch 场景测试可能继承本机代理环境配置。回归从公开接口验证这些行为；测试载入场景前暂时清除代理入口，结束后恢复原环境值。

## 编辑器渲染检查

非 batch 编辑器探针调用实际菜单与 `StartExperiment`，确认初始暂停且零派发；暂停期间现实时间继续，游戏时间不变。一次公开推进将游戏分钟从 720 改为 721，派发 2 个固定请求。四个身体均有 Sprite 和局部观察，界面显示四张状态卡、资产、观察来源和时间。

第二轮截图经人工查看有效；第一轮窗口图片因 DPI 重复缩放造成裁切，保留原证据但不用于界面验收。探针现使用实际窗口屏幕矩形，并验证桌面边界与图像内容。第二轮退出 Play 后恢复原场景布局，开发场景 SHA-256 前后均为 `371875a819f0f492d6da01da36882d4e4a22c37cbb451810392243a7df3b2915`。

见[窗口截图](four-agent-entry-evidence/experiment-window.png)、[四人场景](four-agent-entry-evidence/four-resident-scene.png)、[便携探针结果](four-agent-entry-evidence/probe-result.json)。原始结果位于 `Logs/agent-platform/editor-entry-20260919-b/`；完整互动与严格回放由 PlayMode 场景测试验证，渲染探针单独验证入口、暂停、推进、四人显示及退出恢复。

## 异常与结论边界

- 初次运行缺少 Git LFS 实体资源，引起 Sprite/场景测试失败；完成 LFS checkout 后重跑场景验证。没有为此重建或提交场景资源。
- 原 Mina/Eli 会面时间使 Eli 在 Sora 请求期间改变其局部观察，固定场景出现 `agent.observation_stale`。Mina/Eli 会面开始时间改为 12:20 后固定流程通过；该错误在真实实验中仍作为正常拒绝结果保留。
- 两轮非 batch 编辑器启动日志均含 `UnityEditor.Search.SearchDatabase` 索引异常；第二轮还记录过许可令牌刷新失败、随后成功读取权益。不能将启动日志描述为无异常。业务入口、渲染与场景恢复分别记录通过结果。
- 记录回放复现已录制输入和响应，不证明再次调用模型会生成相同选择。F/S 质量、多人长期行为及真实费用尚待集成矩阵。
- Unity 自动升级的 ProjectSettings 与本功能无关，不纳入交付差异。工作分支交付不表示已合并主分支。
