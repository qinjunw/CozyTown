## 实施边界

首版提供 Unity 编辑器实验入口，使用现有开发小镇和四名居民。配置包括明确的 F／S 单组或配对选择、固定客户端／记录回放／真实模型、初始资源场景和有界调用。四人共享调度器与预算；资源会面覆盖 Ren／Sora，新增会面配置覆盖 Mina／Eli，沿用现有行为。

实验拥有时间推进和输入。玩家输入隔离，停止普通自动时钟与自动决策更新；所有推进、保存与读取操作经实验入口记录。首版严格回放只承诺这些已记录输入，不接收任意玩家修改世界。提供原始请求、候选、拒绝、执行观察和最终文本，审计视图不进入 NPC 上下文。

真实／固定记录和回放采用相同的回复交付边界：提供方完成先入队，每次世界输入完成后、决策 Tick 前释放已完成结果。记录两种时间、交付 Tick 和顺序，比较完整规范化请求及配置；只映射已声明的临时身份字段，不改写台词。出现分歧即停止。

每个新实验重新装配世界与四人，配对使用共同配置分别初始化；读档有独立事件与世界代次，保持原表达配置、预算及旧请求隔离。实验初始共享预算显式设为每分钟 16 次、并发 2；另验证每分钟 8 次的争用与等待。真实模型执行前另冻结场景矩阵和总调用上限，本入口实施阶段不读取密钥。

## 公开测试边界与顺序

沿用已授权的实验入口、观察、客户端／协议、会面、资源及导出记录边界，按垂直切片 RED → GREEN：

1. 从入口核对四人完整初态；未选择表达模式不派发，两个新世界无经历和资产串用。
2. 固定策略从同一共享调度器完成两组互动；覆盖 F／S，核对资产、会面终态及日程恢复。
3. 记录后从同初态回放，核对请求、结果、资产和经历；改时间、事实、模式或配置时停止。补充同 Tick 与乱序响应、超时／取消和纠正。
4. 公开保存／读取入口保留身体、承诺、经历和逻辑决策；早期档不恢复未来信息，跨模式拒绝。
5. 实验视图渲染显示四人状态、来源时间、承诺、经历和结果；导出保留失败及统计分母，回放与真实调用分开。
