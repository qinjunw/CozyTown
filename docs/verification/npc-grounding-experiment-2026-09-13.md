# NPC 环境上下文与资源条件对照实验

## 结论与适用范围

在本次固定请求中，已知不足时的不可行动作选择为 A 7/15、B 8/15、C 2/15。C 在 B 的基础上增加本人余额或库存与交易条款的比较结果，样本中错误选择更少；这一小样本差异尚不能证明长期效果。D 为 0/15，但该组由程序移除了不满足本人条件的选项，不能计为模型推理改善。

台词仍包含未经观察支持的池塘状态、新鲜度与个人观察经历。本次没有证据支持“增加这版上下文即可消除环境编造”。B 只补充请求中可证明的事实、未知项和位置语义，实际场景另补本人身体观察；尚未提供附近对象、资源品质或生产记录的完整感知能力。因此，本结果也不能否定后续提供真实局部环境事实的价值。

建议将**明确自方条件、候选参数校验、提交时宿主复核**作为下一步实施输入；局部观察和事实表达继续按玩法边界讨论。本报告记录实验结果，未采纳新实施 ADR，生产代理默认行为与经济规则未改变。

## 输入与控制条件

| 组 | 模型收到的处理 | 动作集 |
| --- | --- | --- |
| A | 原生产请求，剥离实验元数据 | 原列表 |
| B | A 加事实来源、未知项、时间/目标/实际位置语义及表达指引 | 与 A 相同 |
| C | B 加本人资源条件比较及缺口；已交付对话不再计算交付前条件 | 与 A 相同 |
| D | C 加自方条件不足时的动作过滤 | 移除 invite、accept_invite 或 deliver，保留回退 |

固定阶段为 8 个请求 × 4 组 × 5 次，共 160 次；请求来自既有真实记录，并保留来源及修改说明。双方记忆清空，独立发言探针的 transcript 清空；“Ren 恰有一条鱼”为修改本人数量的反事实请求。40 个请求/重复配对使用不同世界标识，每次调用 ID 独立；这些标识不代表新建 Unity 世界。分组次序轮转，前次输出不进入后次请求。

实际场景为资源充足、卖方缺鱼、买方缺钱、买方已有鱼四种配置，每配置在四组各运行一次，共 16 个不同世界。每轮重建双方资产、承诺、记忆和调度器，从 12:15 开始，最多 12 请求、观察 100 秒，再停止派发并检查 16:40 的恢复。四个 HTTP 端点共享一个 192 次预算；普通活动调用也计数。

请求模型为 `deepseek-v4-flash`，217 次返回模型名均为 `deepseek-flash`。沿用原系统提示词、`json_object`、关闭思考、512 输出 token 上限和 7 秒提供方超时，无自动纠错或重试。系统提示词 SHA-256 为 `ac33dba894886b505ea03d5785fbc323e79a5f72a9ae1769d1d0a27a46465514`；语料 SHA-256 为 `bd13d491c5375977b611f4a5166c64c237d1c0af67631cddaa8f68f988999316`。源文件哈希和实际模型名见各阶段 manifest 与逐次记录。原始 HTTP 请求 payload 未另外保存，提示词/参数一致性由匹配的源码和 manifest 核验。

真实调用期间固定代码、语料和参数。整个预算为 352 次，实际使用 **217 次：固定 160 次、场景 57 次**，剩余 135 次未使用。场景退出后确认在途请求为 0，停止实验代理；没有根据结果追加重跑。

| 指标 | A | B | C | D |

| 自方已知不足仍选不可行动作 | 7/15 | 8/15 | 2/15 | 0/15 |
| 自方已知可行时有效继续合作 | 15/15 | 13/15 | 15/15 | 15/15 |
| 候选必填参数格式错误 | 0/40 | 2/40 | 0/40 | 0/40 |
| 程序过滤过动作的请求 | 0 | 0 | 0 | 15 |
| 提供方错误 | 0 | 0 | 0 | 0 |

每组不足探针包括缺钱邀约、缺鱼答复、缺钱交付各 5 次；可行探针包括正常邀约、正常答复、恰有一条鱼答复各 5 次。“有效继续合作”要求动作、必填字段及当前标识正确，固定请求并未执行交易。等待和拒绝按场景判断，不将始终等待视为任务成功。

C 剩下的两次错误都发生在 Sora 只有 10 金币、价款为 25 时仍发出邀请。这里的“不可行”按当前固定价、无赊账或未来筹资能力的实验目标定义；若以后允许条件性预约，应另定承诺语义和指标。

B 的两个可行邀约把 `planId` 放在 `social` 内，原代理白名单移除该对象后，候选缺少顶层 `planId`。原始输出证明它们是字段层级错误，不能描述成模型完全未生成计划标识，也不能计为有效邀约。结果和原文见 [固定请求独立核验](npc-grounding-experiment-2026-09-13/fixed-audit.json)。

## 台词盲评

40 条独立发言打乱次序，隐藏分组及预期结果，向两个 Codex 审阅者提供同一份人物设定、时间、交易收据和已知事实。两个审阅者先独立标注，再在解盲统计前核对分歧；原评、分歧、裁定及映射均保留。该方法不是人工验收，语义判断仍有不确定性。

| 每组 10 条台词 | A | B | C | D |
| --- | ---: | ---: | ---: | ---: |
| 明确无依据事实断言 | 5 | 5 | 7 | 7 |
| 其中与已知事实矛盾 | 2 | 0 | 0 | 0 |
| 仅有歧义，未计明确错误 | 4 | 0 | 3 | 1 |
| 未标记以上问题 | 1 | 5 | 0 | 2 |

无依据表示输入不能支持，未必表示世界中事实为假。矛盾为其中的子集，例如下午问早安、已有交付收据却说稍后交付。明确愿望、提问、主观喜好和未来料理意图不计作已完成事实；“鱼很新鲜”“今早亲眼看见芦苇边涟漪”则需要对应证据。新鲜食材偏好、修辞和当日计划的歧义单列，不用于扩大明确错误数。

本轮交付后的对话不附加资源条件或过滤，因此 **B/C/D 在发言探针中使用相同处理**；它们的差异不能归因于自方条件计算。每组只有双方各 5 条，亦不能据此认定某组会长期增加或减少编造。完整标注见 [盲评与分歧裁定](npc-grounding-experiment-2026-09-13/dialogue-adjudication.json)。

## 双方真实场景结果

| 初始配置，每格 1 轮 | A | B | C | D |
| --- | --- | --- | --- | --- |
| 资源充足 | 交付并结束 | 交付并结束 | 交付并结束 | 交付并结束 |
| Ren 缺鱼 | 邀约后取消 | 宿主拒绝不可行交付 | Ren 拒绝邀请 | Ren 拒绝邀请 |
| Sora 缺钱 | 邀约后取消 | 宿主拒绝不可行交付 | Sora 等待 | Sora 等待 |
| Sora 已有鱼 | 宿主抑制需求 | 宿主抑制需求 | 宿主抑制需求 | 宿主抑制需求 |
| 全组提供方调用 | 16 | 14 | 13 | 14 |

16 轮均通过初始化、资产变化和 16:40 日程恢复检查。四轮充足配置各转移 1 条鲤鱼和 25 金币，其他配置没有转移；宿主阻止了非法资产变化。已有鱼时没有产生买鱼机会，这是宿主需求规则的结果。

A 的充足场景有一次对话请求记录 `TaskCanceledException`，关联结果为 `agent.decision_stale`；提供方最终仍返回候选，属于过期结果丢弃，未记为提供方超时。该轮仍完成交付和会面结束。原始失败保留，不能将测试通过解释为所有候选均被执行。

场景中记录了本人实际位置、路线状态及约定站位检查；B/C/D 仅获得本人位置和双方是否到场的会面事实，不获得伙伴坐标或私有资产。目标地点没有被当成当前位置。场景只有每格一次，结果用于验证真实接线和观察行为，不能估计长期可靠率；固定请求结果与场景结果使用不同分母。

位置采集没有单独时间戳，观察元数据使用请求时间；排队后的普通请求可能稍后才获取坐标，因此本轮不能证明坐标与请求时间严格同步。普通活动没有关联会面时，到场状态保留 null（未知/不适用）；独立审计首次把它误判成必须等于原始观察默认 false，复核冻结方案后修正了审计预期，保留了十条涉及记录和修正说明。

完整轨迹见 [16 轮场景记录](npc-grounding-experiment-2026-09-13/scene-world-runs.json) 和 [场景独立核验](npc-grounding-experiment-2026-09-13/scene-audit.json)。
