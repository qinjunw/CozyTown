# Agent 换绑输入失败保护验证

- 日期：2026-09-17。
- 任务：[确保 Agent 换绑失败时保留原对象图](https://github.com/qinjunw/CozyTown/issues/87)。
- 基线：`96034ae38e116c59409cef8349f47c294608581d`；测试边界见[验证方案](npc-binding-plan-2026-09-17.md)。
- 执行：Unity `6000.5.5f1`，独立检出中的批处理 EditMode／PlayMode；PlayMode 保留图形设备，测试入口不传 `-quit`。真实模型调用为 0。

## 问题与修复

原控制器先替换资源、居民世界和时钟，再校验会面资源及决策角色。候选图缺少参与者时，错误发生在旧时钟已经解绑、新时钟尚未订阅的阶段，原居民代次或可查询角色随之改变。

本次将候选资源保存在局部变量中，使用候选时刻初始化新世界，然后验证会面参与者、资源归属和决策角色。检查通过后才发布引用、切换订阅。会面板与调度器复用各自的绑定校验，调度器实例不被替换；失败前的预算、真实在途任务、会面及活动继续有效。

独立静态审计另发现：未配置的动画组件会在身体提交时访问空 renderer，导致同类部分替换。新增公开测试复现后，居民预检开始验证可选动画组件的 renderer 及 4 张待机／8 张行走 Sprite，复用原 `Configure` 的检查条件。合法动画及逐帧 `Apply` 的行为未改。复核确认该发现已解决，没有剩余可具体指出的缺陷；静态复核不替代下表的执行结果。

生产差异限于控制器、会面板、调度器、居民及动画组件五个文件。新增的 [NpcBindingPlayModeTests](../../Assets/CozyTown/Tests/PlayMode/NpcBindingPlayModeTests.cs) 从公开入口验证；模型替身只控制请求完成时机，存储替身用于返回指定坏档。没有修改存档格式、额度参数或默认模型配置。

## 输入与证据边界

[输入核验](npc-binding-2026-09-17/input-audit.json)检查了 1,028 个项目文件，其中 342 个 C# 文件。隔离工程来自上述提交，只叠加本票据的五个生产文件及测试／meta；其余输入按 Git 内容、允许的换行差异和 LFS 实体摘要核对。共享工作区的美术、农田、场景及其他未提交文件未进入测试或交付。

Unity 自动升级隔离工程的 `ProjectSettings.asset`，并生成 `SceneTemplateSettings.json`；这两项作为显式输入例外记录。前者的键与摘要、[设置差异](npc-binding-2026-09-17/isolated-settings.diff)、后者的固定内容均保留；没有将测试环境描述为与 Git 设置逐字节相同。输入核验不构成 DLL／PDB 源码校验和证明。

[运行清单](npc-binding-2026-09-17/manifest.json)包含筛选条件、退出码、各阶段计数、源码摘要和原始 XML／日志摘要。发布 XML 替换本机路径、统一换行并去除行尾空白，程序核验每个 test-case 的属性与原始 XML 完全相同；[校验和清单](npc-binding-2026-09-17/checksums.json)固定发布文件，目录属性禁止 Git 转换证据换行。三份 RED 测试源码保留其执行时版本；第二、第三次 RED 的生产前置阶段在运行清单中明确标记。

本修复保证已验证的输入与本地配置失败发生在引用发布前，不提供任意外部取消回调或事件访问器抛错后的通用事务回滚。普通读档已经提交权威数据后发生的重建通知异常，由[明确读档提交后重建失败的处理边界](https://github.com/qinjunw/CozyTown/issues/91)处理；跨调度器重配额度由[约束运行中决策重配的预算与在途请求](https://github.com/qinjunw/CozyTown/issues/88)处理。完整逻辑快照依然尚待实现，本次通过不能替代其 13 组恢复验收。
