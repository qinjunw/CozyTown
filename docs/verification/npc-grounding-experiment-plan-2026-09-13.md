## 分组与归因

| 组 | 处理 | 解释范围 |
| --- | --- | --- |
| A | 原系统提示词和原协议上下文，剥离实验元数据 | 同期基线 |
| B | 增加结构化事实、时间与位置语义、未知项和事实表达指引 | 整体披露方案的效果；包含表达指引，不能归因于单纯增加 token 或事实数量 |
| C | B 加自方数量/余额与条款比较的明确结果；动作列表与 B 相同 | 自方条件说明的增量效果 |
| D | C 按自方已知不足过滤 invite、accept_invite 或 deliver | 系统候选限制效果；仍调用模型，不将过滤计为模型推理改善 |

每组均使用 `deepseek-v4-flash`、既有 `json_object` 协议、关闭思考、512 输出 token 上限及 7 秒提供方超时。模型实际别名、提示词/代码/语料哈希记录在结果中。没有协议纠错或提供方自动重试，原始失败保留；原代理基础校验与额外的候选字段诊断分开记录。

B 的范围是当前请求可证明的信息与实际身体观察，周边植物、天气、鱼的品质和未公开资产保持未知。目标位置不作当前位置；到场须来自实际路线状态和约定站位。当前实验不提供完整场景感知扫描，不据物品目录缺项断言整个世界不存在某物。历史台词是说话者声明，不能覆盖当前事实。C/D 不提供对方库存和全局可交易判断，未检查的容量、预留与对方条件仍标未知；交付后的对话不重新检查是否还持有交付前资源。

## 固定请求比较

[固定语料](../../Tools/agent_proxy/grounding_corpus.json) 包含 8 个请求：Sora 正常/缺钱邀约、Ren 正常/缺鱼答复、Sora 缺钱交付、Ren 恰有一条鱼答复，以及双方各一条交付后的独立发言。

请求源于既有真实记录。清空个人记忆；发言探针统一清空 transcript，以免把旧模型台词当成新实验事实。Ren 恰有一条鱼是只修改本人数量的反事实请求，明确标记，不宣称已经运行该世界。原始来源及修改保留在模型看不到的语料元数据中。

8 请求 × 4 组 × 5 次 = 160 次，按请求/重复轮转组序。每次调用独立，不继承前次输出；每个请求/重复的四组共用配对标识，调用 ID 独立。新 ID 表示实验隔离，不代表重建了 Unity 世界。模型未提供固定采样种子；游戏种子不能替代它。

资源指标：首轮是否提出已知自方无法承担的动作、合法候选率、可行条件下的主动选择。等待/拒绝不自动算错，也不能凭始终等待宣称任务成功。协议缺字段与资源判断分开。发言按支持、矛盾、无依据、明确推测及个人表达逐句标注；盲化分组后由独立代理复核，不使用额外计费模型作裁判，也不将语义标注视为绝对真值。

## 双方实际场景

通过独立显式 PlayMode 测试复用现有四种配置：资源充足、卖方缺鱼、买方缺钱、买方已有鱼。共 16 轮，每种配置在 A/B/C/D 各运行一次，用于检查真实闭环与接线，不能据单轮推算某组长期可靠率。

每轮重新加载隔离检出场景，重建双方资产、世界、承诺、记忆和调度器；首个调用前检查状态为空、资源准确、世界 ID 唯一。双方均调用真实模型，普通活动也计费；按正常倍率从 12:15 推进，单轮最多 12 请求、观察 100 秒，停止派发后统一检查 16:40 的资产及日程恢复。

场景次序沿用 `(repeat + offset) % 4`，分组取 `offset`，因此每个四轮块都包含四种配置与四个组，每配置最终覆盖四组。共享一个代理服务预算，不为每个组重置。实验元数据记录实际本人和伙伴位置，模型仅获得本人观察及双方已到场的授权会面事实；未到场时不公开伙伴坐标。

记录每轮邀请、接受、到场、交付、结束、错误、资产守恒和恢复；“已有鱼不触发机会”属于宿主规则结果。不同模型选择会改变轨迹，完整场景与固定请求分开统计。

## 预算、验证与发布

固定请求预算 160 次；场景预算 192 次；整个实验上限 352 次。失败同样消耗预算，不自动续额，不因结果不佳重跑至成功。新建证据目录与报告；中断保留原尝试，后续重启需要扣除已尝试调用并另行记录。

实现按 RED → GREEN 验证上下文隔离、资金 24/25/26、库存边界、交付后状态、字段诊断与共享预算；Unity 在隔离检出中验证实际初始化、观察和分组。运行 Unity 时不修改其 Assets。完成必要回归后固定实验代码，真实执行期间不调整提示词、判断规则或语料。

代码、方案、原始上下文/候选、代理计数与归纳报告推送独立分支，PR 保持 Draft。研究方案仍属于实验，不自动替换生产策略；是否采用及局部观察的玩法边界继续在后继票据讨论。
