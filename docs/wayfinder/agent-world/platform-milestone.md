- 类型：PRD 的阶段范围与验收计划。以下是据此制定的任务边界，尚未完成的玩法决定保留在独立票据中。

## 1. 完成边界

第一版完成时，开发者能从指定初始状态启动 Mina、Eli、Ren、Sora，观察内置事件驱动的活动与交互，保存并恢复同一组逻辑状态，重放已记录的决策，并对真实模型做独立的多次实验。每次实验能回答“谁因什么信息做了什么，宿主实际执行了什么，消耗多少调用，为什么失败或恢复”。

| 范围 | 交付要求 | 验收证据 |
| --- | --- | --- |
| 四人自主运行 | 四人分别持有人设、状态和合法行动机会；用现有移动、邀约、交谈及资源交付能力配置实验 | 四人在同一世界推进；固定接受策略覆盖包含四人的互动组合；真实模型可拒绝，记录原因与终态 |
| 世界与人物连续性 | 保存全部已实现、会影响后续行为的逻辑状态；关联数据来自同一保存边界 | 逐项状态清单、迁移规则与保存／恢复对照；读早期存档后没有未来经历泄漏 |
| 有界运行 | 继续执行已有权限、行动仲裁、资产检查与调用约束 | 重复、迟到、失败及竞争不会造成重复交付、旧结果写入或预算绕过；等待有期限和可见结果 |
| 可观测 | 提供角色观察入口和可导出的实验记录 | 可关联触发、所见事实及来源时间、候选、拒绝或执行结果、承诺、经历与调用统计 |
| 可重复实验 | 初始快照、内容／人设／协议／模型配置和输入轨迹有版本；固定替身、记录回放、真实模型三类运行可区分 | 固定输入可复核宿主结果；真实实验每轮校验四人初始化，报告全部完成、失败、中断和排除样本 |
| 可交付版本 | 提供一个干净检出的候选提交及操作说明 | 从该提交启动实验、保存读取和查看记录的验收完成；PR 栈依赖明确，是否合并单独注明 |

本轮使用已实现的能力验证 Agent 机制。自主捕鱼、烹饪、种植闭环，新需求／长期关系系统、向第三人传播声明、大规模社会模拟及新地图不作为第一版的完成条件。它们需要新的范围决策，不能仅因实验中出现相关台词就登记为已有能力。

## 3. 完整逻辑快照的设计边界

“完整”按已实现的行为状态逐项审计。快照契约必须将每个相关字段归入“保存”“由已保存数据重建”或“运行期状态”，并说明恢复后的可观察结果。尚不存在的需求、关系或职业生产系统不因此新增。

| 类别 | 契约必须覆盖的问题 |
| --- | --- |
| 世界与资源 | 时间、种子、已用随机状态、角色／商店资产、农田和畜牧是否来自同一时点；已有确定性算法所需版本如何识别 |
| 人物与身体 | 当前活动、期限、日程进度、位置与路径进度如何恢复；精确续走与合法归位对承诺及观察有什么影响 |
| 社交与资源协作 | 邀请、接受、预约、到达、交付凭据、对话轮次和终态如何保持双方一致；同一次恢复不重复交付 |
| 个人信息 | 经历、亲历声明、来源、时间、可见参与者及容量如何保存；历史观察与当前所见如何区分 |
| 逻辑待办 | 未处理事件、冷却、已消费机会、等待决策和等待发言如何恢复或重新验证；不丢轮次、不集中补发 |
| 实验配置 | 内容、人设、动作协议、表达模式与版本能否准确还原或明确拒绝不兼容配置 |

HTTP 请求、`Task`、取消源、事件订阅和 Unity 对象引用不写入存档。恢复时重建这些运行对象，成功发布后使用新运行代次，旧响应不能写入恢复后的世界。对尚未取得结果的逻辑决策按契约重新校验及派发；已经发生的模型费用不能回退，当前进程的限流窗口与实际在途计数也不能通过读档清零。

快照不承诺下次真实模型会说同样的话。相同输入与已记录输出的回放用于复核宿主行为；重新请求真实模型用于观察行为分布。回放记录并驱动游戏时间、调度器现实时间、事件及响应完成顺序；跨运行的临时 ID 明确映射，核对请求内容与配置后才提供对应记录。轨迹分歧应报告并停止该次回放，不能按序盲用旧回复。回放仍经过宿主校验，不凭历史台词重做交易。

用户已在[完整逻辑快照契约](../../AGENT_SNAPSHOT_SPEC.md)中采纳精确位置与路线恢复、进行中邀约／交谈续接、旧存档保留已有数据并初始化缺失状态。[ADR-0019](../../adr/0019-complete-logical-snapshots-and-agent-continuation.md)记录新格式对旧恢复规则的局部修订；运行实现尚未改变。

## 5. 测试与停止条件

固定替身优先验证确定性约束，真实模型评测只回答固定替身无法回答的行为与表达问题。下表为验收矩阵；游戏天数、场景组合、重复次数、调用上限和行为指标判定在最终评测执行前预登记，不能看到结果后改门槛。

| 层次 | 必须覆盖 | 通过或报告规则 |
| --- | --- | --- |
| 状态一致性 | 保存时分别处于闲置、邀请、赴约、交付前后和交谈中；连续读取同档、读取早期档、旧版迁移和坏档 | 对照契约核对全部逻辑字段及关联；资产、经历、承诺和身体一致；输入失败保留原运行状态 |
| 生命周期故障 | 旧请求忽略取消、晚到成功／失败、换绑失败、重配、关键重建失败及恢复重试 | 旧响应没有写入；无重复副作用；预算和在途占位不被清零；提交后异常有明确状态及恢复方式 |
| 四人共同负载 | 四人在同一世界跨日；同时有机会、争用同一参与者／地点、预算耗尽、拒绝与超时 | 每人都有处理机会或有期限且可解释的回退，不能因固定遍历顺序长期遗漏；占用释放、默认生活继续 |
| 信息边界 | 相同逻辑初态的 F／S 对照；当前观察、历史声明、过期事实和私有信息 | 宿主检查与模型表达分别评分；流程通过不代表自由台词零编造；结构化组另记事实选择与重复 |
| 重复与回放 | 每轮重建四人及全部资源；存档／配置、时间输入、事件和响应顺序匹配；临时 ID 映射后核对请求 | 初始化不通过不得计作有效样本；回放分歧报告并停止；失败和中断保留；仅统计真正发出的调用，不把回放算成真实样本 |
| 交付 | 干净检出、既有回归、从实验入口开始到导出记录 | 记录提交、依赖 PR、运行命令、测试结果和未完成项；无需从共享工作区复制未提交文件 |

第一版停止扩展的条件是：上述能力在同一候选提交贯通，确定性约束通过，真实模型结果及限制可复核，使用者按说明能独立复现实验。新发现的资产、信息权限、旧响应或恢复一致性缺陷继续阻塞交付；纯表达风格和新增玩法进入后续范围讨论，不据此无限扩张当前版本。
