# CozyTown 工程交付计划

## 1. 交付原则

- 每个里程碑交付一个可观察行为，不以目录、空接口或占位断言作为完成证据。
- 领域规则保留在 `CozyTown.Runtime`；Unity 组件只负责输入、生命周期、场景引用和表现更新。
- 跨模块状态变更由应用协调器执行。UI、NPC 文本和场景对象不得直接修改其他模块内部状态。
- 自动化默认不访问真实网络、不调用计费模型、不读写玩家正式存档。
- 每个 Git 提交只包含一个可解释的行为或基础设施变更；提交前检查暂存差异、编译结果和相关测试。

## 3. 质量门槛

每个里程碑合入前执行与风险相称的检查：

1. `Packages/manifest.json`、锁文件和程序集定义可以被 Unity 解析。
2. Unity Editor 完成脚本编译，日志不存在 `error CS` 或 `Scripts have compiler errors`。
3. 相关 EditMode 测试通过；涉及场景生命周期时增加 PlayMode 或人工冒烟证据。
4. Debugger 复现并定位失败路径，修复后保留能阻止回归的测试。
5. Reviewer 检查模块依赖、失败原子性、稳定 ID、存档边界和 AI 写权限。
6. `git diff --cached --check` 通过，提交信息描述问题、变更和验证结果。

## 4. M1 工作包

M1 于 2026-08-28 完成。Unity `6000.5.5f1` 在隔离 worktree 中重新导入项目并执行两个 EditMode 测试程序集，结果为 56 passed、0 failed、0 skipped。

### WP1 应用协调层

- 睡觉只推进一次游戏日。
- 农田与畜牧使用同一目标日期结算。
- 任一结算失败时恢复时间、农田和畜牧快照，并返回稳定错误码。
- 测试覆盖成功、重复日期、无效状态和回滚。

### WP2 默认内容

- 定义 3 种作物、3 种鱼、5 个配方、商店物资、1 只鸡和 3 至 4 名 NPC 的稳定 ID。
- 所有配方输入均能由种植、畜牧、钓鱼或商店获得。
- 启动前校验种子、产物、商品、鱼和配方引用的物品 ID。

### WP3 Unity 适配

- Bootstrap 显式创建服务对象图并向场景控制器提供窄接口。
- 玩家移动组件只处理输入和刚体速度。
- 交互探测器只选择 `IInteractable` 并触发应用用例，不包含领域规则。
- 当前阶段允许使用调试 HUD，不把临时 UI 结构写入领域程序集。

## 6. M3 验收结果

- 商店、种植、畜牧、钓鱼和烹饪分别通过窄应用协调器向 Unity 提供只读状态与单次命令入口；场景 Presenter 不取得钱包、背包、原始领域服务或完整服务集合。
- 商店及四个生产服务在首次库存写入前捕获快照。依赖先变更再返回失败时恢复原状态；恢复失败返回模块级稳定诊断码。
- 农田和畜牧只接受连续下一日结算。跨日协调器让时间、农田和畜牧对同一目标日提交，任一模块失败时恢复三者快照。
- 正式开发场景包含商店、NPC、床、农田、鸡舍、池塘和厨房 7 个交互点。六个功能面板共用玩家模态输入门控，互斥打开并在关闭、禁用或撤销时恢复原控制状态。
- 自动化场景从 300 金币购买土豆种子、鸡饲料和两份盐，完成种植、养鸡、固定鲤鱼、两次跨日、收获和两道料理；出售剩余土豆、两份料理和鸡蛋后余额为 405，再买一份种子后余额为 385。
- 2026-08-29 使用 Unity `6000.5.5f1` 在隔离 worktree 执行完整测试。EditMode 108/108、PlayMode 22/22 通过；编译错误、测试失败、未处理异常与运行态装配错误的日志匹配数均为 0。

## 7. M4 验收结果

- `GameSaveCoordinator` 在同一逻辑时点捕获时间、金币、背包、农田和畜牧快照，并在恢复前校验 schema、必需载荷和跨模块日期一致性；恢复中任一步失败会回滚五个模块。
- `JsonFileSaveStorage` 使用独立 schema v1 JSON 数据包。保存时在目标目录写入并复读验证临时文件，再原子替换正式槽位；空槽、截断或结构损坏、未来版本和无效载荷返回稳定且可区分的结果，失败不会破坏上一份有效存档。
- AI 对话只接收复制出的只读 DTO，成功结果只包含 `text`、`emotion` 和 `action`。代理请求不携带仓库内模型密钥；超时、传输异常、提供者错误、空文本、结构错误和非法标签统一落入 NPC 固定回退，并保留关联 ID 与回退原因。
- 自动化用例向 AI 文本注入赠送物品、扣除金币、推进日期、收获和喂食等指令，钱包、背包、时间、农田和畜牧快照均保持不变。
- 正式场景复用既有 NPC 交互点并提供 4 名 NPC；右上角非模态面板提供单槽位保存和读取。批处理模式使用内存存档，常规 Editor Play 和构建使用应用持久化目录中的 `CozyTown/main.json`。
- 2026-08-29 使用 Unity `6000.5.5f1` 执行完整测试。EditMode 151/151、PlayMode 26/26 通过；编译错误、测试失败、未处理异常与运行态装配错误的日志匹配数均为 0。
- 真实模型服务地址、30 条离线评测、延迟与成本汇总、Windows 构建、录屏和作品集说明仍属于 M5，未计入 M4 完成范围。
