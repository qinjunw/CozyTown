# ADR-0015：统一居民活动仲裁并隔离世界运行代次

- 状态：Accepted，本轮实施采用；完整 Agent 社交与模型接线仍按地图继续。
- 日期：2026-09-12。
- 依据：用户授权从世界与人物两方面开始迭代；[Agent 世界 PRD](../AGENT_WORLD_PRD.md) 的首轮运行基础。

现有日程在每段时间推进时直接重设居民目的地，会覆盖后续临时活动。当前读档按日程重建位置，也不能让旧世界的异步候选在新状态生效。

## 决策

- 由 Runtime 中的角色世界管理每个稳定 NPC ID 的日程、当前临时活动、状态修订和待处理事件。Unity 居民从该入口取得活动目标，并继续使用现有路线和碰撞检查。
- 可信游戏调用方可以提出一个有截止时刻的活动候选；目标必须可用，类型限定为工作或休息，持续时间大于零且最多一个游戏日。临时活动不能用 `Home` 把任意地点当作住宅并隐藏身体。
- 每人同一时刻最多一个临时活动；重复、旧修订或忙碌请求被拒绝，不替换当前活动。日程边界可以产生通知，但不覆盖有效临时活动。
- 活动有效区间为接受时刻至截止时刻之前。到期或取消后立即采用当时日程。一次大步时间推进必须在活动起止和日程边界分段，保持实际行程连续。
- 睡眠清除小数分钟时，沿用已有完整睡眠时长。目标查询不回到最近已接受世界时刻之前，避免新活动在首个小段短暂恢复旧日程。
- 成功读档、世界重建或更换绑定世界创建新的运行代次，并清空本轮临时活动与待处理通知；旧代次候选被拒绝。同一世界重复绑定保持状态。
- 小数分钟更新本身不产生角色通知；日程目标变化、跨日、活动变化和重建产生按角色隔离的通知。同类未消费通知合并为最近一次，队列不是完整活动历史。
- 大步推进的日程通知比较推进前后的目标，不补发已经错过的中间活动机会；实际移动仍按经过的日程和活动边界分段。通知用于下一次决策，不能作为完整行程记录。

## 取舍与边界

各角色单独覆盖移动目标会形成多个身体控制者；共享仲裁保留一个目标来源，但新增调用必须经过活动与版本检查。状态采用角色配置和组合，不按人物姓名派生类型。

本轮沿用 [ADR-0013](0013-deterministic-town-life-and-derived-npc-presence.md) 的按日程重建位置，代价是临时活动不随存档恢复。持久承诺和精确恢复由后继票据另行定义。

活动被接受只代表安排生效；位置、到达和受阻仍从 Unity 执行结果观察。到达后在活动期限内停留，生产、交付和社交完成有各自后续契约。

[ADR-0002](0002-deterministic-domain-and-ai-boundary.md) 的模型对话权限保持有效。本轮没有把新入口交给真实模型，也没有增加经济或存档写工具。新模型行动协议须由后继决策明确。

## 验证

通过公开角色世界、居民控制器及既有时间／读档用例验证角色隔离、事件合并、期限、重复与旧请求、实际移动和大步／小步一致性。结果由 [实现世界事件与人物活动仲裁](../wayfinder/agent-world/tickets/world-events-and-activity-arbitration.md) 记录。
