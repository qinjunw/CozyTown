# ADR-0017：先形成会面承诺，再以实际到达开启交谈

Ren 与 Sora 现有休息日程只重叠 15 游戏分钟，按当前倍率约为 7.5 现实秒。采用提前邀约、双方接受后原子预约未来活动和地点的会面协议；原有工作持续到约定开始时刻，实际移动层确认双方到达后才开放发言。该选择保留日程倍率，并让模型响应不必全部挤在休息交集内。

状态由宿主管理，模型只能提出邀请、接受、拒绝、本人发言或结束候选。每人同时最多一项会面，地点在承诺期间独占；反向邀请、重复答复、路径失败、超时和读档均有确定结果。发言按当前轮次交替、长度与总轮数有界；结束时释放双方活动与地点，恢复当前时刻日程。会面经历只记录宿主确认的事件，当前仅保留有界内存记录，持久化留给后继任务。

使用真实 DeepSeek 服务时，由本地代理将游戏候选协议转换为模型请求；模型密钥不进入 Unity 场景或仓库。用户指定的请求标识为 `deepseek-v4-flash`，服务端实际返回型号另行记录。固定客户端测试证明协议和执行规则，真实调用记录用于检查接口、延迟与这次场景的实际结果，两类证据分别报告。
