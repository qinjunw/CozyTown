# ADR-0016：以结构化机会驱动有界自主决策

- 状态：已采用；按用户授权实施第二轮重构。
- 日期：2026-09-12。
- 票据：[接入有界决策与渐进式上下文](https://github.com/qinjunw/CozyTown/issues/52)。

现有对话由玩家交互触发，不能承担后台自主生活。新增独立决策入口，由世界事件产生机会，将单个居民的只读上下文交给模型客户端；宿主校验候选后才进入活动仲裁。模型客户端不持有世界或经济写接口。

第一种机会限定为默认日程进入休息窗口且没有有效临时活动。初始化／重建、日期／日程变化、活动结束可以检查此条件；活动接受本身不再次唤醒模型。工作和居家已有默认安排时继续执行日程。定向邀请和资源需求在后继票据增加。

初始上下文提供本人身份、人设、目标、触发原因、本人已知地点 ID 及活动约束；模型可按需查询其中一个地点的可达性，再提出等待或访问候选。角色与世界代次由宿主绑定，输出不能指定另一名执行者。披露检查与执行检查分别进行。

调度由 Unity 主线程推进，以现实时间管理调用预算、冷却和超时，以游戏时间及世界修订判断机会有效期。实验默认上限为每现实分钟 8 次客户端调用、同时 2 次实际在途请求、每人 1 个决策、每个决策 2 次模型往返、普通冷却 30 秒、单次请求 8 秒、整个决策 12 秒、机会有效期 30 游戏分钟。数值可配置，尚不代表模型表现或玩家体验验证。

模型续调和失败尝试也消耗请求预算。取消或超时后忽略迟到结果；如果客户端没有结束实际请求，其并发槽保留至任务结束，避免仅取消逻辑状态便突破真实并发上限。读档取消旧世界决策，保持同一调度器的现实时间预算。

本决策对 [ADR-0002](0002-deterministic-domain-and-ai-boundary.md) 增加独立的受检查活动候选路径。既有对话协议继续只返回文本与表现；自主动作仅能安排本人已有合法地点的工作／休息活动，沿用 [ADR-0015](0015-resident-activity-arbitration-and-world-epochs.md) 的期限、版本和读档语义。金币、物品、时间推进和存档写能力不进入模型接口。

测试先通过固定客户端验证结构化触发、上下文隔离、预算、续调、超时、失效和实际移动。真实代理使用独立版本化协议；旧对话端点不能被自动视为自主行动端点。

实现入口为 Runtime `NpcDecisionScheduler`、外部边界 `INpcDecisionClient` 和 Unity `CozyTownTownLifeController`。代理客户端通过[协议 v1](../NPC_AGENT_PROTOCOL.md)提供等待、地点查询和访问候选。默认启动器只在非批量运行且显式配置 `COZYTOWN_AGENT_PROXY_ENDPOINT` 后接入 HTTP 客户端。固定客户端不依赖端点配置。

取舍：第一轮披露只能查询本人日程地点的可达性，未引入地点知识库、社交承诺、角色资源或完整记忆。机会结束后只向本人下一次决策提供同世界内的结果码；诊断保留最近一次上下文和最终候选。拒绝或故障后不会自动无界重试。后续能力需扩展机会与操作契约，并继续由宿主验证实际世界结果。
