# ADR-0008：以语义碰撞边界和独立世界实体收口 Scene-01

- 状态：已接受
- 日期：2026-08-31

## 背景

Scene-01d 已完成常驻 UI 的信息架构，但人工场景检查发现三个可观察问题：系统菜单文字与按钮底色对比不足且齿轮仍带有错位底框；四座建筑、农田和池塘缺少实体碰撞；世界中只有 Mina 一个 NPC 交互点，却在同一面板内提供四名 NPC 的选择。

本轮属于人工 Scene-01 验收前的 Scene-01e 收口，不增加玩法系统。它必须保留既有经济、生产、存档和 AI 只读边界，不接入真实 AI 服务。

## 决策

- 交互种类继续保持 `Shop`、`Npc`、`Bed`、`Farm`、`Coop`、`Pond` 和 `Kitchen` 七种；物理交互实体由 7 个调整为 10 个，其中 NPC 从 1 个拆为 Mina、Eli、Ren 和 Sora 四个独立世界实体。
- 四名 NPC 继续使用现有稳定 ID、人设和固定回退对话。每个世界实体只打开对应 NPC 的对话投影，不在一次世界交互中显示四人选择器。
- 四座建筑使用覆盖贴图下方约 3/5 的静态实体碰撞，并在门口保留向内延伸的凹槽；贴图上方约 2/5 作为可通行背面区域。建筑交互 Trigger 只覆盖门口，不覆盖屋顶或外墙。本阶段不实现角色位于屋顶后的透视遮挡。
- 池塘使用近似岸线的多边形实体碰撞；钓鱼 Trigger 使用同一岸线外缘，使玩家从可达岸边一圈都能获得 `E` 提示。农田本体使用独立实体碰撞，既有农田交互仍从边缘触发。
- 实体障碍位于交互点层级之外，避免 `InteractionProbe2D` 沿 Collider 父链把整座建筑误识别为可交互对象。
- 系统菜单四个主按钮使用深木色 `#6F5A4A` 与奶油色 `#FFF4D6` 的高对比组合，标签字号为 10。右上入口只显示 `16×16` 灰色齿轮，不显示按钮底框或文字子节点。
- 为 Eli、Ren 和 Sora 补齐与 Mina 同规格的 `16×24`、BottomCenter 世界 Sprite；不增加行走动画、日程、任务或关系系统。

本决策取代 ADR-0006 和 PRD A1 章节中“交互点数量保持 7 个”及“单一世界 NPC”的局部约束；七种交互语义、领域接口和玩法结果保持不变。ADR-0007 的 UI 分区、只读投影和共享输入门仍然有效。

## 公开测试缝隙

- UI 通过公开 `Button`、`Image`、`Text` 和 `RectTransform` 验证颜色、字号、Sprite、锚点、子节点和按钮状态。
- 世界边界通过场景中公开的非 Trigger `Collider2D` 路径、Bounds 和 Physics2D 接触结果验证；测试不读取私有序列化字段。
- 门口和池塘交互通过 Trigger 的公开几何、`PlayerInteractor2D.CurrentPromptAnchor`、真实玩家位置和交互输入验证。
- NPC 通过公开 `TownInteractionPoint2D`、Presenter 的稳定 `NpcId`、SpriteRenderer、Transform 坐标及 View 当前 NPC 状态验证。
- 四名 NPC 的站位不得与任一非 Trigger 世界障碍重叠；任意两名 NPC 至少相距 3.0 世界单位并位于地图边界内。世界 Sprite 的职业特征必须与对应头像和稳定 ID 一致。

## 验证规则

- 每个 UI、碰撞和 NPC 竖切先建立能够命中当前缺陷的 RED，再加入最小 GREEN。
- EditMode 验证 10 个物理交互实体、七种交互语义、碰撞几何、四个 NPC 身份与 Production 引用；PlayMode 验证玩家不能穿越建筑、农田和池塘，以及每名 NPC 只打开自己的对话。
- 场景升级入口必须可重复执行；连续两次升级后场景内容一致。
- 完成目标测试后运行全量 EditMode 和 PlayMode；日志不得包含编译错误、丢失引用或未处理异常。
- 自动化不替代 `320×180`、`640×360` 和 `1280×720` 下的人工可读性、碰撞手感、门口进入深度、池塘岸线贴合度和 NPC 构图检查。

## 后果

世界中的可见占地与玩家可达空间具有一致的公开场景契约，NPC 身份也从对话列表落实为可观察的世界实体。代价是场景升级器需要维护障碍几何、四个 NPC 实体和额外世界 Sprite；这些变化不进入领域状态或存档 schema。

## 复审条件

只有在建筑真正切换室内场景、NPC 开始移动或遵循日程、农田允许逐格行走，或钓鱼改为朝向/抛竿玩法时，才复审本 ADR 的门槽、静态站位和岸线 Trigger 方案。
